Linear/Logistic Regression | Gradient Descent | KNN | ML Types

Linear Regression

Slope = Δy/Δx, R² measures proportion of variance explained
Best-fit line minimizes sum of squares of errors

Logistic Regression

Outputs probabilities, uses cross-entropy (log-loss), threshold = 0.5

Gradient Descent

Batch: uses entire dataset, Stochastic (SGD): uses one sample
Learning rate controls step size, too large → overshoot/diverge

KNN

Majority vote of nearest neighbors, larger K → smoother boundary

ML Types

Supervised (labeled), Unsupervised (unlabeled), Reinforcement
