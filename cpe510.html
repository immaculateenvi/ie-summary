Social Engineering | Malware | Firewalls | Cryptography | DES

Social Engineering

Manipulating people to reveal information

Malware

Trojan: disguised as legitimate
Worm: self-replicating, spreads via network
DoS: Denial of Service, overloading system

Firewall

Network security device, protects perimeter, internal firewalls segment networks
DMZ: exposes services to internet

Cryptography

DES: symmetric key encryption
Vigenère cipher: polyalphabetic substitution
Bell-LaPadula: confidentiality model
Clark-Wilson: integrity model

Password Security

Hashing (one-way encryption), Salt (adds random data to prevent rainbow table attacks)
