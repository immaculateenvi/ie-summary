📈 MTS 102: Mathematics II (Calculus)

Limits | Differentiation | Integration

📌 Limits

lim_{x→0} sin x/x = 1, lim_{x→0} (1-cos x)/x = 0, lim_{x→∞} 1/x = 0

📐 Differentiation

d/dx(xⁿ) = nxⁿ⁻¹, d/dx(eˣ) = eˣ, d/dx(ln x) = 1/x
Product: d(uv)=u dv+v du, Quotient: d(u/v)=(v du - u dv)/v², Chain: dy/dx = dy/du × du/dx

∫ Integration

∫xⁿ dx = xⁿ⁺¹/(n+1) + C, ∫eˣ dx = eˣ + C, ∫1/x dx = ln|x| + C, ∫sin x dx = -cos x + C, ∫cos x dx = sin x + C
