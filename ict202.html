🗄️ ICT 202: Database Management System

SQL | Normalization | Keys | Data Models | Anomalies

SQL Commands

DDL: CREATE, ALTER, DROP
DML: SELECT, INSERT, UPDATE, DELETE
DCL: GRANT, REVOKE

Database Keys

Primary Key: unique identifier
Foreign Key: references another table
Surrogate Key: artificial identifier

Normalization

1NF: atomic values
2NF: no partial dependencies
3NF: no transitive dependencies
BCNF: stricter version of 3NF

Anomalies

Insertion, Update, Deletion anomalies caused by redundancy

Armstrong Inference Rules

Reflexivity, Augmentation, Transitivity (for functional dependencies)
