📱 ICT 409: Mobile Communication and Network

Cellular Systems | Frequency Reuse | Handoff | Capacity

Cellular Systems

Key characteristic: frequency reuse
Reuse factor = 1/N (N = cluster size)
Required SIR ≈ 15 dB

Handoff

Transferring connection between cells
Dwell time: time user stays in a cell (depends on speed, cell size, traffic)
Intersystem handoff: between different systems

Capacity Enhancement

Cell splitting (smaller cells), Sectoring (dividing cells into sectors), Microcells

Co-Channel Interference

Interference from cells using same frequency, smaller reuse factor = more interference
