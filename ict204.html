📶 ICT 204: Signals & Systems

Periodic Signals | Convolution | LTI Systems | Fourier Transform

Signals

Periodic: x(t) = x(t+T) for all t
Aperiodic: does not repeat
Unit step: u(t) = 0 for t<0, 1 for t≥0
Unit impulse: δ(t), ∫δ(t)dt = 1

Convolution

x(t) * h(t) = ∫ x(τ)h(t-τ)dτ

δ(t) * x(t) = x(t), u(t) = ∫δ(t)dt

LTI Systems

Linear: superposition applies
Time-invariant: delayed input → delayed output
Impulse response: h(t) characterizes system

Frequency Domain

Fourier transform: H(jω) = ∫h(t)e^(-jωt)dt
Transfer function: H(s) = Laplace transform of h(t)

System Types

Causal: depends on past/present only
Anti-causal: depends on future
Nyquist rate: fs > 2fmax
