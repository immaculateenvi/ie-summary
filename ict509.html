📊 ICT 509: Data Structure and Algorithm

Graphs | BFS/DFS | Trees | Recursion | Complexity

Graphs

Simple graph: no loops or parallel edges
Directed graph: in-degree and out-degree
Complete graph: n(n-1)/2 edges

Trees

Spanning trees: n^(n-2) for complete graph (Cayley's formula)

Graph Traversal

BFS: uses Queue (FIFO), O(V+E)
DFS: uses Stack (LIFO), O(V+E)

Recursion

Base case stops recursion, Recursive step breaks problem into sub-problems

Complexity

Array access: O(1), Insertion at beginning: O(n)
Ω(n) = best-case (lower bound)
