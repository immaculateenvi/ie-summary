💡 EEE 419: Digital Electronics

Logic Gates | Boolean Algebra | Flip-flops | Counters

Logic Gates

AND: output 1 when all inputs 1
OR: output 1 when any input 1
NAND: output 0 when all inputs 1
NOR: output 0 when any input 1
XOR: output 1 when inputs differ
XNOR: output 1 when inputs same

Boolean Algebra

Y = (A·B)' (NAND), Y = (A+B)' (NOR), Y = A⊕B (XOR)

Flip-flops

SR: Set-Reset, invalid state (1,1)
JK: overcomes SR invalid state
D: Data and Clock
T: toggles when T=1

Counters

Count clock pulses, made from flip-flops

Multiplexers

Selects one of many inputs, Demultiplexer routes one input to multiple outputs
