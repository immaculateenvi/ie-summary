🎮 EEE 201: Control Systems

Open/Closed Loop | Transfer Function | Stability | PID

🔄 Open vs Closed Loop

Open: no feedback, simple, inaccurate; Closed: feedback, accurate, expensive

📈 Transfer Function

G(s) = C(s)/R(s), Closed-loop = G/(1+GH), Characteristic: 1+GH=0

⚙️ PID Controller

P: proportional gain, I: reduces steady-state error, D: improves transient response

📊 Stability

Routh-Hurwitz, Root locus, Nyquist; stable if all poles in left half-plane
