Set Theory

Union: A ∪ B = {x | x∈A or x∈B}
Intersection: A ∩ B = {x | x∈A and x∈B}
Complement: A' = {x | x∉A}
Formula: n(A∪B) = n(A) + n(B) - n(A∩B)

Example: 50 students, 30 Math, 25 Physics, 10 both → neither = 50 - (30+25-10) = 5

Mathematical Induction

1. Base case (n=1)   2. Assume P(k) true   3. Prove P(k+1)

Sum of first n numbers: 1+2+...+n = n(n+1)/2

Sequences & Series

Arithmetic: aₙ = a₁ + (n-1)d, Sₙ = n/2[2a₁ + (n-1)d]
Geometric: aₙ = a₁·rⁿ⁻¹, Sₙ = a₁(1-rⁿ)/(1-r), S∞ = a₁/(1-r) (|r|<1)

Quadratic Equations

ax² + bx + c = 0 → x = [-b ± √(b²-4ac)]/2a
Discriminant: D = b²-4ac
D>0: 2 real roots, D=0: 1 root, D<0: complex roots
Sum of roots: α+β = -b/a, Product: αβ = c/a

Binomial Theorem

(x + y)ⁿ = Σ ᵑCₖ xⁿ⁻ᵏ yᵏ, where ᵑCₖ = n!/(k!(n-k)!)
Properties: ᵑCₖ = ᵑCₙ₋ₖ, ΣᵑCₖ = 2ⁿ

Trigonometry

sin²θ + cos²θ = 1, 1 + tan²θ = sec²θ
sin(A±B) = sinA cosB ± cosA sinB
sin2θ = 2 sinθ cosθ, cos2θ = cos²θ - sin²θ
Sine rule: a/sinA = b/sinB = c/sinC
Cosine rule: a² = b² + c² - 2bc cosA
